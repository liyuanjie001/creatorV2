出海动力 · 海外社媒一站式矩阵宣发平台（前端演示 Demo）
=====================================================

【最快体验】
解压后双击打开「网页版/index.html」即可浏览全部页面，
无需安装任何环境（Chrome / Edge 浏览器均可）。

【本地运行源码】
进入「源码」目录，执行：
  npm install
  npm run dev
然后按终端提示在浏览器打开 http://localhost:5173

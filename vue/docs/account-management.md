# 帐号与分组管理

更新日期：2026-11-05。

- 全部帐号不展示总览卡片。帐号分组和授权状态通过表头图标筛选，与搜索组合使用；`q`、`group`、`status` 查询参数支持刷新、返回恢复。
- 点击分组或备注打开编辑弹窗，保存后更新用户的本地工作区；批量移动使用相同分组顺序。
- 帐号分组默认列表，`view=list/grid` 保存展示方式。分组数组顺序为持久化顺序；手柄可拖动或用上下方向键移动，更多菜单也提供上移、下移。点击查看切换全部帐号，应用分组并清除搜索和授权状态筛选。
- 分组更多菜单提供重命名和删除；默认“未分组”只能排序。删除分组将帐号移入“未分组”。计数不包含已删除帐号。
- 帐号行操作仅有删除。确认框显示待发布、已排期任务数量，确认后取消这些任务并移除所有项目关联。发布中禁止删除，服务层再次检查，避免确认期间状态变化。
- 帐号通过 `deleted` 标记隐藏，历史记录继续保留名称、用户名。已删除帐号不能用于发布或项目选择；再次授权相同用户名恢复同一身份，不恢复任务和项目关联。
- 所有行为沿用本地模拟，不调用真实平台授权、删除或发布接口。

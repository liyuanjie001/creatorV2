# 设置中心

头像入口进入 `/me`，默认展示我的权益。页面左侧“设置”菜单依次为我的权益、账号中心、帮助与反馈、消息中心；窄屏改为可横向滚动的顶部导航。`section=benefits|account|help|messages` 保存当前子页，未知值展示我的权益，原 `/settings` 不变。

侧栏底部头像悬停或获得键盘焦点时，在头像上方展开相同的四个快捷入口，面板左侧与头像按钮对齐。鼠标可直接向上移入面板，离开后收起；点击外部或按 Escape 关闭。头像上按方向键可进入链接，Tab 顺序浏览，选择后进入对应子页并收起面板。点击头像仍直接进入个人中心，窄屏触控也可使用。

我的权益复用套餐和积分账本，支持权益详情、升级套餐和独立积分充值。账号中心显示默认人像，支持 1—30 字昵称、演示验证码修改密码、退出登录；Google 登录在 Google 管理密码，demo 不修改密码。独立账号昵称保存在身份凭据中，demo 昵称单独本地保存，重新登录继续使用。

帮助与反馈分为“用户反馈”和“帮助中心”两个页签，默认打开用户反馈，支持方向键切换。用户反馈包含提交表单和本地记录；帮助中心提供分类、搜索和可展开问答。切换页签保留未提交的反馈及搜索、分类条件。本地反馈需问题类型、10—2,000 字描述，联系方式选填（最多 100 字）。记录显示“已保存到本地，尚未发送客服”，不调用客服接口、不产生处理状态或回复。相同类型、描述及联系方式的反馈不可重复保存。

用户反馈表单右侧展示“联系客服”卡片，复用套餐购买页联系商务经理的 `/wecom-qr.png` 企业微信二维码；窄屏排在表单下方。扫码联系与本地反馈保存独立，页面明确提示可添加后发送问题描述和截图，保存反馈不会自动发送给客服。

反馈使用 `chuhai-feedback-v1:<用户 ID>`，消息使用 `chuhai-notifications-v1:<用户 ID>`。损坏或无法读取时显示空状态和错误，保留原数据，不覆盖。保存失败明确提示；消息保存失败不会改变支付、积分和账号结果。

用户反馈在问题描述下提供可选图片附件，最多 3 张，支持 JPG、PNG、WebP，单张原图不超过 5 MB。图片读取成功后压缩至最长边 1280 像素、每张最多约 500 KB，再随反馈记录保存在本机；支持缩略图预览、放大查看和提交前删除。切换帮助页签保留已选图片，保存成功清空表单，保存失败保留内容供重试。反馈记录显示附件数量，刷新后可在详情继续查看图片。历史无附件记录兼容；相同文字、联系方式和图片内容视为重复反馈。

消息包含系统说明、支付成功、账号到账、同步失败及恢复；支持全部/系统/购买分类、未读筛选、详情、单条或全部已读，已读状态刷新恢复。订单 ID 与事件类型组合去重，未支付不生成购买消息，纯积分不生成账号消息。支付消息来自实际订单，到账消息仅在工作区账号同步完成后显示，软删除账号继续视为已交付；刷新或重新登录从订单和工作区补齐缺失消息。首次启用时历史已完成订单标记已读，新事件未读；恢复通知按失败记录生成。

本轮仍使用本地演示身份、支付及账号，不接入真实短信、邮件、客服、消息推送或登录换绑。

“我的权益”卡片下方展示购买记录，包含创建时间、订单号、原订单金额/积分、套餐名称、账号使用权与交付状态、支付方式及订单状态。点击订单号查看详情并复制编号，含账号的已支付订单可前往账号管理；历史手动领取订单保留领取入口。记录按创建时间倒序，每页 10 条，窄屏使用单列卡片。

“刷新订单”只重新读取当前用户的本地账本，不支付待支付订单，不重新计算历史额度，也不触发账号补发。读取失败保留已显示记录并提示错误。当前订单状态只有待支付和已完成：待支付不显示为到账，自动交付未同步时标记已支付/待同步，历史未领取额度单独显示。未增加截图中的已关闭、人工核对等后台状态。

# 充值演示

个人中心的四档充值及“立即充值”打开扫码弹窗，默认支付宝，可切换微信。二维码仅编码 `DEMO ONLY - NO PAYMENT - alipay/wechat` 演示文本，不包含收款地址；SVG 使用 ReportLab 的 QR 编码器生成。点击“模拟支付成功”完成演示订单。“联系商务”继续使用企业微信二维码。

积分服务以 `chuhai-credits-v1:<用户 ID>` 保存余额、累计额度和订单。每个帐号初始 100 积分；订单完成时一次保存订单状态与增加后的余额，保存失败不更新界面。同一已完成订单不会重复入账，未完成订单不增加积分。侧栏与个人中心共享响应式余额，重新登录及刷新后恢复。

当前无真实支付请求、回调或创作扣积分逻辑。本地订单不代表真实交易。

## 新购买自动到账

选择含账号的新订单保存 `deliveryMode: 'automatic'`。购买卡片、支付确认及购买说明均提示“美国 TikTok 账号，付款后自动到账”。支付前不增加积分或账号；演示支付完成后直接生成该订单全部账号，初始已授权、未分组，所有现有及新建项目均可使用。无需选择平台、地区或手动领取。

支付成功显示“已到账 N 个账号，已添加至账号管理”，提供“查看账号”和“关闭”。查看账号关闭弹窗并跳转账号管理；纯积分充值成功仍提供“完成”。账号来源标识为“购买账号”，详情可查看演示用户名、默认隐藏的密码、示例 IP 和美国地区，支持复制。

统一完成入口 `completePurchase` 先调用账本入账，再复用账号恢复逻辑同步工作区，积分服务不反向依赖工作区。支付状态、积分和全部账号记录在一次账本保存中写入。自动交付记录标识为 `automatic:<订单 ID>`，账号标识为 `automatic:<订单 ID>:<序号>`；保存账号所属订单、地区、凭据和示例 IP。重复支付或同步使用已保存记录，刷新不会再次充值或生成凭据。

账本保存失败时订单仍未支付，不增加积分或账号。账本成功而工作区保存失败时显示“支付已完成，账号同步失败”及“重试账号同步”。重试只补齐已保存账号，刷新或重新登录也会恢复缺失账号；已有编辑和软删除记录不会被覆盖或恢复。

## 历史订单继续领取

历史含账号订单缺少 `deliveryMode` 时（包括历史未支付订单）继续使用保存时的金额、积分、数量和原领取流程。新仅积分订单虽然也没有该字段，但账号数量为零，不产生领取余额。历史待领取账号不会自动转换；历史 `p490` 继续读取，新首档为 `p500`。

账号管理不再展示“历史待领取账号”提示卡片及“领取历史账号”入口。历史订单、剩余额度和领取记录原样保留，底层历史领取兼容逻辑继续仅使用历史已完成订单，新自动到账订单不参与。

历史领取记录及地区、凭据原样保留。领取先保存记录再同步工作区，同一请求重试不重复扣减。领取失败后表单锁定，支持重试或刷新恢复。删除账号不返还历史余额，所有购买账号均跨项目可用；授权状态、项目归档及发布内容校验继续生效。

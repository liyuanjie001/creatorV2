# 新用户引导

新注册、快捷新用户与首次 Google 用户进入业务页面后，自动开始五步引导。已有用户和固定演示帐号不自动开启；侧栏底部的“新手引导”可随时从头重看。

每一步通过 Vue Router 打开实际业务页面，并用镂空高亮和说明卡指向真实控件，不再创建独立演示工作区：

1. 项目：跳转项目首页。没有项目时，说明卡提供项目名称输入框，明确说明“下一步”将创建真实项目并进入自由创作；可跳过而不创建。
2. 创作视频：打开选定项目的 `section=gen&mode=normal`，高亮自由创作入口及实际创作面板。
3. 我的作品：打开 `section=publish&tab=creations`，高亮作品入口及上传控件。没有作品时，仅在说明卡内以小动画解释“作品 → 去发布 → 发布配置”。不添加示例作品。
4. 去发布：打开 `section=publish&tab=configure`。有作品时复用可编辑的草稿；没有草稿时，通过原有服务为实际作品准备一个待配置草稿。没有作品时展示发布配置的真实空状态，仍可使用实际账号选择器、绑定流程及项目关联入口。不会自动授权、选择账号、提交发布或伪造发布成功。
5. 发布成功：介绍发布后查看数据的方式，打开该项目的 `section=analytics&report=content`。说明卡中的“视频数据”和“账号数据”可切换真实数据页面；没有账号时进入帐号管理。没有内容或采集记录时保留实际空状态。

背景页面与高亮控件可以操作，业务弹窗和下拉菜单显示在引导层上方。上一步与下一步均同步路由；结束引导后停留在当前真实页面。关闭按钮、跳过以及说明卡内 Escape 均结束引导。减少动态效果偏好下，流程动画显示为静态。

版本、当前步骤、所选项目和状态按用户保存在 `chuhai-guide-tour-v1:<用户 ID>`。刷新会恢复步骤并打开对应页面；项目被删除或归档时，选择其他有效项目，没有项目则回到第一步。完成或跳过后不再自动弹出。存储失败时在当前会话保留状态。

项目首页统一移除顶部开始使用提示条、底部爆款推荐及其显示／隐藏按钮，保留项目创建和侧栏爆款视频入口。

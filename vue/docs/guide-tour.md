# 新用户引导

新注册、快捷新用户与首次 Google 用户进入业务页面后，自动开始四步引导。已有用户和固定演示帐号不自动开启；侧栏底部的“新手引导”可随时从头重看。

每一步通过 Vue Router 打开实际业务页面，并用镂空高亮和说明卡指向真实控件，不再创建独立演示工作区：

1. 项目：跳转项目首页。没有项目时，说明卡提供项目名称输入框，明确说明“下一步”将创建真实项目并进入自由创作；可跳过而不创建。
2. 创作视频：打开选定项目的 `section=gen&mode=normal`，高亮自由创作入口及实际创作面板。
3. 我的作品：打开 `section=publish&tab=creations`，高亮作品入口及上传控件。没有作品时，在说明卡内显示 16:9 的“视频发布演示”动图占位，下方循环提示“我的作品 → 去发布 → 发布配置”。发布录屏准备好后，可将 `GuideTour.vue` 中的 `publish-demo-placeholder` 替换为同尺寸的 GIF 图片。不添加示例作品。
4. 账号管理：从“我的作品”直接打开 `/accounts`，高亮侧栏帐号管理入口、账号统计与绑定账号按钮，介绍账号绑定、授权状态、分组备注及数据看板。没有账号时展示真实空状态；刷新恢复此步骤无需已有项目。引导不再自动进入发布配置或创建发布草稿；发布演示保留在第三步的动图占位中。

背景页面与高亮控件可以操作，业务弹窗和下拉菜单显示在引导层上方。上一步与下一步均同步路由；结束引导后停留在当前真实页面。关闭按钮、跳过以及说明卡内 Escape 均结束引导。减少动态效果偏好下，流程动画显示为静态。

版本、当前步骤、所选项目和状态按用户保存在 `chuhai-guide-tour-v1:<用户 ID>`。刷新会恢复步骤并打开对应页面；旧五步进度中停留在“去发布”或“账号管理”的记录均续接到新的第四步“账号管理”。项目被删除或归档时，选择其他有效项目，没有项目则回到第一步；账号管理不依赖项目。完成或跳过后不再自动弹出。存储失败时在当前会话保留状态。

本次更新后新注册、首次 Google 登录和快捷新用户的初始赠送为 50 积分，登录时写入该用户的积分账本。已有用户余额、旧引导记录、演示账号及团队成员分配额度不变。首次完成、跳过、关闭或在说明卡内按 Escape 结束引导后，弹窗显示“新用户赠送50积分已到账”“+50 积分”和“我知道了”，停留在当前页面。通知标记按用户持久化，重看引导、刷新和重新登录不会重复提示或发放；切换用户关闭弹窗。积分或通知标记保存失败时显示错误及重试入口，不会把未确认的积分显示为已到账，也不会覆盖损坏或已存在的账本。

项目首页统一移除顶部开始使用提示条、底部爆款推荐及其显示／隐藏按钮，保留项目创建和侧栏爆款视频入口。

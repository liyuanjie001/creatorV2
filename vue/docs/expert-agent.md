# 专家模式 Agent 工作台

专家模式使用本地 Mock Agent 任务状态机承载视频创作流程。创作首页保留素材、产品卡和视频参数入口，首次发送后在同一页面进入对话工作台；右侧仅显示可收起的历史会话。

任务数据按当前用户和会话保存到 localStorage，包含消息、上下文、交互卡片、版本和确认记录。卡片状态依次支持待操作、选择中、已提交、已确认、已锁定、已过期和不可操作。选择提交与内容审核确认分开，局部修改会使受影响的下游结果过期，重新审核后才能继续。

默认演示流程覆盖产品事实核对、策划与脚本、稳定编号分镜、关键帧 Visual QA、渲染审核、验收归档及测试计划。用户明确要求 Hook 或 CTA 数量时按要求生成；未指定时提供一条完整英文脚本和中文释义。事实依据、图片可观察信息、未知项和禁止声明分开保存，未知内容不会自动成为卖点。每个镜头保留提示词、素材版本、验收标准和实际时间码待填写字段，可下载 CSV 供手动导入飞书。三种创作风格使用不同的 Mock 场景和表达模板；自然语言输入可修改风格、Hook、镜头、人物或产品资料，并提示影响范围。最终渲染使用现有生成任务服务，结果与“我的作品”共享任务 ID 和进度，当前只展示 Mock 封面与创作说明，不生成真实视频文件。


## 三轮案例交流

案例以产品与痛点卖点、创作方向与钩子、脚本与关键帧三个交流阶段推进。Mock Agent 根据原始需求推荐风格，并将确认的角度和钩子带入脚本。第一轮允许补充未知资料，产品信息仍需人工核对。第三轮在对话中保留脚本入口，镜头在弹窗内切换查看及编辑；关键帧与 QA 门禁保持不变。

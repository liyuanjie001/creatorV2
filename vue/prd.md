# 出海动力工作空间原型需求

## 个人工作空间与 TikTok 内容闭环（2026-11-03）

主流程为“发现参考 → 创作成片 → 发布 → 分析 → 再创作”。默认一级导航为项目、爆款视频、素材库、帐号管理；项目内固定提供自由创作、产品卡、发布管理、数据分析、项目设置。导航与创作模式写入路由地址，可通过刷新和浏览器历史恢复。旧项目视图、旧路由及 Roxy 窗口管理仍保留。

登录原型支持邮箱或含国家区号的手机号注册、密码及验证码登录、密码重置、模拟 Google 登录、邀请码可选和演示帐号入口。注册凭据使用带盐摘要并保存在浏览器 IndexedDB；用户业务数据按用户隔离。原型验证码为固定演示码，不代表真实身份验证。

帐号管理包含帐号列表、分组、模拟 TikTok 授权成功与失败、重复授权更新、重新授权、项目关联和解绑确认。真实令牌不由前端保存。爆款视频支持 TikTok 与 FastMoss 视频详情链接的模拟解析、去重、失败场景和进入指定项目的普通或专家创作。

自由创作保留常规创作控制台，并增加带历史侧栏的专家对话流程；成片数据独立于发布任务保存。发布任务按“一个成片 + 一个帐号”建模，支持批量逐行配置、文案建议、披露设置、定时、记录、状态查询模拟及失败重试。项目分析提供总览、内容明细、筛选排序、列配置、分页、CSV 导出、内容属性确认和按属性洞察；不可用数据与真实零值分开显示。

本版本是可持久化的前端交互原型。验证码、Google、TikTok OAuth、链接解析、视频生成、发布及指标采集均使用模拟服务；真实平台令牌、发布调用和分析指标须在后端接入并按平台授权能力验证。

## 目标与范围

以 RoxyBrowser 窗口管理多平台账号，将内容表现统一放到数据分析页面。演示使用 Vue 前端和本地数据，不连接后端、真实 Roxy 或网站统计，保持现有视觉风格。

原需求中的窗口、视频和平台分析继续保留，入口从窗口管理移到数据分析，并补充账号监测。改造原因、可获取条件和暂不纳入的报表依据，见[数据分析改造原因与指标边界](docs/analytics-design-rationale.md)。

## 窗口管理

- 首次输入本地 Roxy API Key，提供一键填入演示 Key。
- 同步项目列表，展示项目名称和窗口数量，勾选后模拟同步。
- 以窗口展示所属项目、平台账号、登录状态和采集状态。空窗口不自动增加账号。
- 每个平台选一个目标账号，同一账号可以关联多个窗口。身份需要实际登录检查，存在 Cookies 不代表登录有效。
- 支持搜索、筛选、恢复登录、重新选择同步项目和重置演示。
- “查看数据”进入数据分析，携带项目、窗口和平台筛选。
- 只保留窗口数、去重账号数和登录待恢复等管理信息，不再内嵌内容报表。

## 数据分析

### 总览

展示当前管理账号、窗口、已识别视频和登录待恢复数量，以及近 7／30／90 天的播放、点赞、评论增量和趋势。平台汇总与详情使用同一份内容数据，并标明可用数据的覆盖范围。

### 账号监测

按项目、窗口、平台、账号名称和运营阶段筛选。账号按平台身份去重，展示所有关联窗口、当前粉丝、周涨粉、区间播放中位数、登录状态及详情入口。

“未分阶段、测试期、放量期、暂停”是手动维护的内部运营标签，独立于登录与采集状态。账号详情提供采集演示、所属窗口入口和视频详情入口。

### 内容明细

展示视频所属账号、发布时间、时长、区间表现与有来源的高级指标示例。详情区分未采集、历史不足、采集失败与采集能力未验证，给出原因和最近采集时间。

当前只对已明确标记的演示场景展示高级指标。平均观看时长、完播率、前 3 秒留存不互相替代；缺少首小时快照时不倒推首小时播放。

### 对比分析

支持窗口、账号、视频和平台四个维度，选择 2～4 项对比。窗口、账号和视频对比使用同平台及同一时间范围。历史不完整或没有内容的项目不参与对比。

合计按视频 ID 去重。窗口存在共用账号时提示不能直接相加。跨平台播放采用各自原始口径，不表示跨平台去重人数。

## 相关入口与保存

项目详情展示该项目关联的窗口和账号，并提供窗口管理与数据分析入口。新建任务按项目和平台列出已同步账号；共用账号只选择一次，并指定执行窗口。

绑定、采集记录和运营阶段保存在独立的 localStorage 数据中，兼容已有绑定。API Key 原文不保存。重置演示清理窗口与分析记录，保留访问密码验证和妙记。

## 本轮不纳入

- 官方流量池、固定推荐阈值、停止推流或数据冻结判断、同池均值。
- 根据播放下降判定限流、未定义的号损率、自动加投或预算系数。
- 未经验证的 5A 人群模型、观众兴趣推断和活跃时段报告。
- 网站进站、链接生成、订单、转化漏斗、转化率和 ROAS。

网站指标需要额外的埋点、来源链接、订单和广告数据条件。其后续设计要求保留在独立说明文档中。

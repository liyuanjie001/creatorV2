# 出海动力 · Vue 交互原型

Vue 3 + TypeScript + Vite 的个人工作空间原型。一级导航依次为项目、素材库、爆款视频、帐号管理、数据分析；项目二级导航分为创作（自由创作、专家模式）和管理（产品卡、发布管理、数据采集），项目设置位于侧栏底部齿轮入口。旧 Roxy 窗口管理仍可从帐号管理的“更多”入口进入，旧项目页和历史路由也继续保留。

## 启动开发环境

使用 Node.js 22.12 或更新版本，在当前目录执行：

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://127.0.0.1:5173`。

## 设置访问密码

编辑当前目录的 `.env`，使用小写配置项：

```dotenv
password=你的访问密码
```

首次运行时，先将 `.env.example` 复制为 `.env`，再设置自己的密码。`.env` 已加入 Git 忽略规则，不会随仓库分发。

所有业务路由都需要先输入密码，验证成功后回到原页面。浏览器会将校验标记写入 localStorage，后续访问和刷新无需再输入。清除站点存储后需要重新验证。如果浏览器禁用存储，只在当前会话内记住权限。

通过访问锁后，原型还会展示独立的应用内登录页。可使用“体验演示帐号”进入，也可走注册、验证码登录、密码登录、找回密码和模拟 Google 登录流程。验证码原型码为 `123456`，注册邀请码可留空；演示流程不发送真实验证码，也不会连接 Google。个人帐号凭据摘要与本地媒体存放在 IndexedDB，业务演示数据按当前用户分开保存在浏览器中。

## 功能入口

- **爆款视频**：浏览推荐素材，粘贴 TikTok 或 FastMoss 视频详情链接解析参考，并选择项目、产品卡和创作模式。
- **帐号管理**：表头筛选、点击编辑分组及备注，支持帐号删除确认和待执行任务取消；分组支持列表／缩略图切换与排序；“更多”菜单保留 Roxy 窗口管理入口。
- **项目工作区**：项目导航状态保存在地址中；自由创作支持普通模式、专家对话模式和创作记录。项目内还包含产品卡、发布管理、数据采集和项目设置；数据采集沿用原有项目内容分析页及地址。
- **发布管理**：管理成片、逐条配置帐号和文案、选择立即或定时发布、查看任务状态并单独重试失败项。
- **数据分析**：查看发布内容快照、筛选排序、维护内容属性、关联历史内容及导出 CSV。

所有身份验证、验证码、Google、TikTok 授权、链接解析、AI 创作、媒体生成、发布与数据采集均为前端模拟服务。原型不会取得或保存真实 TikTok 令牌，不会发帖，也不提供真实视频生成或平台指标采集。正式接入需增加安全的后端身份服务、TikTok OAuth 与内容发布 API、媒体处理和指标读取服务。

开发环境修改密码后重启 `npm run dev`。生产环境修改密码后重新执行 `npm run build` 并部署，旧的校验标记将失效。未配置密码时保持锁定。

这是前端演示访问锁，不是服务端鉴权。浏览器用户可以检查和修改前端代码与本地存储。

## 演示窗口与内容分析

打开侧栏的**窗口管理**，按以下步骤体验：

1. 点击**开始绑定与同步**，再点击**一键填入演示 Key**。
2. 点击**同步账号**，勾选 RoxyBrowser 项目，再点击**开始同步**。
3. 在窗口列表或详情中检查登录状态。失效账号支持**模拟恢复登录并同步**，列表另有采集状态。
4. 点击窗口的**查看数据**，进入带项目、窗口和平台筛选的数据分析页。
5. 在**总览、账号监测、内容明细、对比分析**中切换。对比支持窗口、账号、视频和平台，最多 4 项；窗口、账号、视频使用同平台数据。
6. 在账号监测中手动调整运营阶段，刷新后保留。阶段不改变登录状态，也不自动触发投放。

演示包含 5 个项目、11 个窗口、20 个去重平台账号和 57 条视频。GlowUp 官方 YouTube 关联两个窗口，用于展示共用账号去重；任务仅为该账号选择一个执行窗口。

数据分析展示未采集、历史不足、采集失败及采集能力未验证场景。总览标明完整数据的覆盖范围；缺少历史的内容不参与对比。重新采集首次发现的内容不会补造历史。指标中的真实 0 与缺失值分别显示。

窗口绑定和恢复记录使用 `chuhai-window-demo-v1`，兼容此前的绑定数据。运营阶段独立保存于 `chuhai-analytics-stages-v1`。**重置演示**清除窗口绑定、采集和运营阶段，保留访问锁与妙记。输入的 API Key 不写入存储，也不会调用真实 RoxyBrowser。

报表使用固定演示日期 `2026-10-22`，由同一份内容每日数据汇总。当前只做内容分析，没有网站进站、成交、ROAS、官方流量池或推流状态报表。

关于这些取舍、指标条件及未来网站归因的说明，见[数据分析改造原因与指标边界](docs/analytics-design-rationale.md)。

## 构建和预览

```sh
npm run build
npm run preview
```

生产文件位于 `dist`。通过 HTTP 服务器访问该目录。路由使用 Hash 模式，资源路径为相对路径，可部署在静态服务器的子目录中。

## 验证迁移

```sh
npm run verify:coverage
npm run lint
npm test
npm run build
```

`verify:coverage` 检查全部页面、项目栏目和 Vue 组件编译，并比较原工程文件的 SHA-256。如果只复制了 Vue 工程，检查会跳过原工程对照。

`npm test` 在 jsdom 中挂载真实 Vue 组件，验证导航、表单、生成、素材操作、妙记存储及窗口同步和报表交互。jsdom 没有浏览器布局，测试为 SVG 图表提供固定尺寸与文字测量，不验证截图。

## 运行浏览器验收

本机安装 Google Chrome 后执行：

```sh
npm run test:e2e
```

如果使用 Playwright 自带的 Chromium，执行：

```sh
npx playwright install chromium
PLAYWRIGHT_CHANNEL=chromium npm run test:e2e
```

测试在 1440px 和 1280px 视口访问页面、检查浏览器错误并保存页面截图。测试使用端口 4173 的生产预览，需要先完成构建。失败记录位于 `test-results`。
